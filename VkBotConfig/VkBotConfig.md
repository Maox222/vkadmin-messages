# Конфигурация VK-бота

Бот управляется двумя JSON-файлами которые лежат рядом с `.dll` в папке `publish/`.  
Никакой пересборки кода не требуется — достаточно отредактировать файл и перезапустить сервис.

---

## `vk_keyboards.json` — меню и кнопки

Отвечает за структуру клавиатур: какие кнопки показывать, в каком порядке и куда они ведут.

### Верхний уровень

```json
{
  "enabled": true,
  "menus": [ ... ]
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `enabled` | `bool` | `true` — кнопки включены, `false` — бот работает без кнопок (все сообщения идут оператору) |
| `menus` | `array` | Список меню. Каждое меню — это одна клавиатура привязанная к payload |

---

### Объект меню (`menus[i]`)

```json
{
  "payload": "start",
  "one_time": true,
  "rows": [ ... ]
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `payload` | `string` | Уникальный ключ меню. Должен совпадать с `payload` кнопки которая его вызывает. Ключ `"start"` — стартовое меню (показывается при нажатии встроенной кнопки «Начать») |
| `one_time` | `bool` | `true` — клавиатура скрывается после нажатия кнопки. `false` — остаётся видимой |
| `rows` | `array` | Массив строк. Каждая строка — массив кнопок |

---

### Объект кнопки

Два вида кнопок: **текстовая** (переход в другое меню) и **ссылочная** (открывает URL).

#### Текстовая кнопка
```json
{ "label": "🎮 PlayStation", "payload": "ps", "color": "default" }
```

| Поле | Тип | Описание |
|------|-----|----------|
| `label` | `string` | Текст на кнопке. Максимум 40 символов |
| `payload` | `string` | Ключ меню которое откроется при нажатии. Должен совпадать с `payload` одного из меню |
| `color` | `string` | Цвет кнопки: `default` (серый), `primary` (синий), `positive` (зелёный), `negative` (красный) |

#### Ссылочная кнопка
```json
{ "label": "⭐ Отзывы", "url": "https://vk.com/..." }
```

| Поле | Тип | Описание |
|------|-----|----------|
| `label` | `string` | Текст на кнопке |
| `url` | `string` | Ссылка которая откроется в браузере |

> **Важно:** ссылочные кнопки не имеют `payload` и не вызывают никакое меню — только открывают URL.

---

## `vk_responses.json` — тексты сообщений

Содержит тексты которые бот отправляет в ответ на нажатие кнопки.  
Каждый ключ соответствует `payload` меню из `vk_keyboards.json`.

### Формат

```json
{
  "ключ_payload": { "text": "Текст сообщения" },
  ...
}
```

### Поддерживаемые плейсхолдеры

| Плейсхолдер | Заменяется на |
|-------------|---------------|
| `{firstName}` | Имя пользователя VK (только в тексте для `"start"`) |

### Медиавложения

Помимо текста к сообщению можно прикрепить фото или видео.

```json
"ps": {
  "text": "Описание услуги для PlayStation...",
  "photo": ["photo-123456789_987654321"],
  "video": null
}
```

```json
"ps_pay": {
  "text": "Инструкция по оплате...",
  "photo": null,
  "video": [ "video123456789_987654321", "video123456789_987654321" ] 
}
```

> ID фото и видео берутся из URL вложения в VK в формате `photo{owner_id}_{media_id}` или `video{owner_id}_{media_id}`.

Если вложений нет — можно использовать короткую форму (просто строка):

```json
"help": { "text": "Текст без вложений" }
```

## Как добавить новое меню

1. Добавить объект в `menus` в `vk_keyboards.json`
2. Добавить кнопку ведущую в это меню в нужном родительском меню
3. Добавить текст ответа в `vk_responses.json` с тем же ключом
4. Перезапустить сервис: `sudo systemctl restart vkadmin.service`

Пример добавления меню "Акции":

**`vk_keyboards.json`** — добавить кнопку в `start`:
```json
{ "label": "🎁 Акции", "payload": "promo", "color": "positive" }
```

**`vk_keyboards.json`** — добавить само меню:
```json
{
  "payload": "promo",
  "one_time": true,
  "rows": [
    [
      { "label": "🔙 Главное меню", "payload": "start", "color": "negative" }
    ]
  ]
}
```

**`vk_responses.json`** — добавить текст:
```json
"promo": { "text": "🎁 Акция месяца: скидка 20% на PS5!\n\nУспейте заказать до конца месяца." } 
```
